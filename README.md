To-Do List Application
live demo : https://hritika-24.github.io/Todo-tasks-using-html-css-js/

This project is a simple To-Do List built using HTML, CSS, and JavaScript. It allows users to add, mark, and delete tasks dynamically.

Features:
  Add tasks to the list.
  
  Mark tasks as completed with a strikethrough effect.
  
  Delete tasks when they are no longer needed.
  
  Local storage support to retain tasks even after refreshing the page.

Technologies Used:
  HTML: Structure of the application.
  
  CSS: Styling for a clean and responsive design.
  
  JavaScript: Logic to manage tasks dynamically.


Installation & Usage:

  Clone or download the project files.
  
  Open index.html in a browser.
  
  Start adding tasks to the list.
